# Security Policy

## Reporting vulnerabilities
Please do not disclose vulnerabilities, credentials, private user data, or exploit details in public issues or discussions.

Use GitHub's **Report a vulnerability** feature under this repository's Security tab if private vulnerability reporting is enabled. If it is unavailable, ask maintainers to provide a private reporting channel without posting technical exploit details publicly.

## Scope and boundaries
This public repository is separate from proprietary enterprise implementations. Never submit private source code, API keys, customer records, real security logs, or live malware samples.

Only test systems you own or are explicitly authorized to assess. Security fixes are reviewed by maintainers before merging. No warranty or response-time guarantee is implied.
